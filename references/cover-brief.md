# 封面：约束、做法与自检

## 先问用户（不要默认做）

三个选项都要讲清差别，**"不做封面"是合法选项，不要漏给**：

- **程序化原创**：按主旨或一个令人印象深刻的情节设计。不撞车、贴合内容；但要迭代，效果取决于设计。
- **官方封面**：用站方插画或出版封面。作者认可；但常只有 300×400、常带平台字样或 3D 书模，需要放大与去字。
- **不做封面**：`build_book.py --no-cover`，不生成封面页与 `images/cover.*`，spine 首项是扉页。后果要说清：阅读器书架会显示书名占位或灰块（Apple 图书会自动生成纯色+书名缩略图），不影响正文；以后想补时用 `inject_cover.py` 直接写回，正文不用重建。若用户后来觉得书架空白别扭，`make_cover.py 书名 作者 --gradient night` 十秒就能出一张"纯渐变底 + 书名作者"的简易封面，够用且不算设计。

**无论做哪种（或不做），书都要能正常打开**：封面只是 epub 的一个可选条目。做了就一律清掉来源字样（「晋江文学城」「长佩文学」「自制精校版」），这是硬要求。

## 硬约束

| 项 | 要求 |
|---|---|
| 尺寸 | 与书的封面槽位一致；新书默认 1600×2400（2:3） |
| 格式 | JPEG，quality 92，progressive |
| 文字 | 必须有书名、作者行；不要平台名 |
| 缩略图 | 200×300 下书名仍可读 |
| 文件 | `主版.jpg` + `备选.jpg` + `preview.png` + `thumb.jpg` |

## 设计思路：从内容里取一个"意象"

四个题材的实例（都能一眼看出和内容的关系；不针对具体某本书）：

| 题材 | 意象 | 做法要点 |
|---|---|---|
| 娱乐圈 / 情感 | 书名那个字从顶部被烧蚀成火星 | 大字实心 + 上缘颗粒化溶解 + 火星柱；黑→暗红渐变 |
| 家庭现实 / 都市 | 城市峡谷里月亮被高楼切掉一块 | 楼群立面 + 窗格 + 巷口冷光 + 一扇暖窗 |
| 都市悬疑 / 港口城市 | 深夜港口，渡轮正驶离 | 天际线剪影 + 水面纵向压缩镜面反射 + 斜雨 |
| 县城现实 / 底层 | 斑驳铁门缝里一线昏黄灯 | 军绿铁门 + 撕过的旧报纸 + 缝隙光 + 湿地面 |

取意象的方法：读 2–3 章 + 番外，问自己"如果只能画一个画面，读者会认同哪一个"。**优先选高潮处或反复出现的物件**（一场雨、一扇窗、一张照片、一条街），而不是抽象的"氛围"。

## 文字层

- 字体优先 Source Han Serif SC Heavy（`C:\Windows\Fonts\Source Han Serif SC Heavy (TrueType).ttf`），作者行用 STSONG 或宋体
- 竖排适合 2–5 字书名；横排适合长书名
- 文字必须压在暗部上：用渐变遮罩（左/下）保证对比；遮罩边缘要羽化，否则会看到硬边矩形
- 书名距边缘至少 8% 边距；作者行与书名之间留 0.5–0.8 倍字号
- 底部小字可留空——不要写平台名

## 去平台字样（用官方图时）

1. 定位文字带（读图量坐标，或先裁剪底条截图确认）
2. 用该带**上下各 20–55 行**的逐列中值做线性插值填充
3. 叠加与周边同强度的颗粒噪声（sd 0.5–2.6），否则会是一块死板的光滑区
4. 40px 羽化蒙版融合
5. 重新截底部条看有没有残字、接缝

常见坑：只覆盖亮字、没覆盖字的光晕 → 会留下"淡淡的鬼影"；取样行本身含字 → 把字抹成一片。

## 自检清单

- [ ] 200×300 缩略图下书名可读
- [ ] 没有平台字样（放大到 200% 检查一次）
- [ ] 文字没有压到人物脸部/关键细节
- [ ] 边缘无硬边遮罩痕迹
- [ ] 与书槽位比例一致（2:3 或书内已有封面比例）
- [ ] 主版与 epub 内嵌封面 sha1 一致

## 写回 epub

```
python scripts/inject_cover.py "书名.epub" cover.jpg
```

只替换封面图片条目（`OEBPS/images/cover.<ext>`），其余条目字节不变（脚本会回读校验），原文件备份为 `.bak.cover`；新图格式与 opf 声明不一致时会自动转码成原格式，并刷新 `dcterms:modified`，否则阅读器仍显示旧封面。

## 归档

```
封面/书名/
├── 书名-主版（已采用）.jpg
├── 书名-备选·<概念>.jpg
└── README.md      # 尺寸/体积/概念/与 epub 内嵌封面 sha1 一致
```

中间稿与旧版备份放临时目录，交付前删掉。
