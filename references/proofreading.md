# 审校：两档的实现细节

## 第 0 步（两档都要）：先读懂文章，再动笔

审校改错的根因，通常不是不懂标点，而是**没读懂这一句在说什么**。同一句话，在"读懂了"的前提下和在"只看到这一句"的前提下，判断往往相反：

- 没读懂 → 觉得"这句没说完"，于是补上一句解释 = 补全留白。
- 没读懂 → 觉得"她"指代不明，于是换成具体人名，结果换错了人。
- 没读懂 → 觉得"的的""在在"是衍字，其实那是作者的口吃式写法。
- 没读懂 → 觉得倒叙缺过渡，于是把时间顺序"理顺"。

所以切卷、开改之前，必须先建立一个**可核对的理解**：

### 0.1 生成材料

```bash
python scripts/read_prep.py _work/norm/chapters.json -o _work/reading
```

产出四份：

| 文件 | 内容 | 用途 |
|---|---|---|
| `outline.md` | 章数/字数/对话比例 + 每章「字数/段数/首句」表 | 找章节节奏、定位长篇/短章、发现异常章 |
| `roster.md` | 「X说/X问/X道…」启发式抽的候选人物名 + 代词计数 | 确认谁在场；**候选有误抽，需人工筛** |
| `style.md` | 最长/最短/含对话/含破折号/含省略号各 2 段 | 一眼记住作者的句子长相 |
| `reading_brief.md` | 九节理解模板（待填） | 切卷的准入材料 |

### 0.2 读，而不是看

长篇不可能逐字读完，但必须读够：

1. 首章（作者如何起手、如何介绍人物）、末章（如何收、留了什么）。
2. 每一卷的首尾章（结构转折处）。
3. `style.md` 抽出的十段（句子节奏、标点习惯）。
4. 全书搜索几个高频词/意象，确认它们是不是母题。

**判断标准不是"读完了"，而是能回答下面三个问题而不查原文**：
- 这本书在写什么？（一句话，包含"谁—想要什么—被什么挡住—结果"）
- 谁在场？每个主要人物的说话方式有什么不同？
- 哪些地方作者是**故意**不写透的？

### 0.3 填 `reading_brief.md`（九节，一节水都不能少）

1. 一句话；2. 主线三到五段；3. 人物表（性别/关系/说话特征/结局）；4. 叙述方式（人称、视角切换、时间线）；5. 语言与语气（长短句、对话标点习惯、用词偏好、**刻意重复清单**）；6. 反复意象/母题及其章节；7. **留白清单**（逐条写章#段）；8. 本作审校红线（针对这本书的具体禁忌）；9. 三句自检。

填完过闸门：`python scripts/check_reading.py _work/reading/reading_brief.md`
- 除第 7 节外，任一节还只有 `{…}` 占位 → FAIL，不许开改。
- 第 7 节空着 → WARN（不阻塞）。

### 0.3b 留白：不是每本都有，但必须专门想过

有的作品通篇直给、结尾闭合，确实没有留白——这很正常，**不要为了填表硬编留白**。但"没想过"和"想过、结论是没有"是两件事：

- 确实没有 → 第 7 节写「本书几乎没有明显留白」+ 依据（叙述直给 / 结尾闭合 / 心理活动全交代 / 每个疑问都在后文解答）。
- 有 → 逐条写清章#段，并写明它省掉了什么。
- **判断法**：问自己"这段作者为什么不多写一句？"
  - 答"想留想象空间 / 故意不说破 / 让读者自己补 / 说了就没味道了" → **是留白**，审校时：
    - 不许替作者补上（不加解释句、不加"从此以后"、不把暗示写成明说）；
    - 不许"修顺"它的模糊（不把"像是"改成"就是"，不把省略号改成句号；
    - 不许在争议清单里建议"补一句更清楚"——这属于改作者的选择。
  - 答"作者赶稿漏了 / 这段确实断了" → 那是缺漏，可进争议清单，但也**不擅自补**，交用户裁决。

### 0.4 把理解带进每一卷

- 分卷 prompt 里必须包含：审校规范 + **`reading_brief.md` 全文** + 该卷源文 + 输出格式。
- 只给源文的子代理，没有上下文，只能按"句子局部通顺"判断，必然改意。
- 合并后做语义复核时，也用同一份 brief 当标尺：**改动处与 brief 的留白清单/人物表冲突的，一律回退。**

### 0.5 常见"没读懂"事故（照此自查）

| 事故 | 症状 | 后果 |
|---|---|---|
| 把留白补成直白 | 开放式段落后面多了一句解释 | 改意（第三层） |
| 把方言/口语改成普通话 | 原文的"俺""咋""冇"被抹平 | 改语气，人物失真 |
| 把刻意的重复当错字 | "在在""的的""起起落落落落"被"修好" | 改节奏与口吃式写法 |
| 把倒叙理顺 | 时间词被补齐、顺序被调 | 改结构 |
| 指代换错人 | 把"她"改成名字，但选错 | 改事实 |
| 把伏笔当病句 | "这句前后不通"被删改 | 破坏后面的呼应 |

## 最高约束（两档都适用，任何情况不得突破）：不得改变作者原意

**「原意」包含三层，任何一层被改动都算出局：**

1. **事实层**——谁、在何时、做了什么、什么因果。年龄、时间、地名、人物关系、事件顺序都属此层。
2. **语气层**——作者对这件事的态度：是确认还是猜测、是心疼还是讥讽、是克制还是直白。限定词（几乎/大概/也许/似乎）、句末助词（吧/啊/呢/罢了/而已）、停顿与破折号都承载这一层。
3. **留白层**——作者故意不写、不说透的部分。留白不是缺陷，是写法。

**最容易犯的六类隐性改意**（字面通顺，所以极难被机器抓到）：

1. 删掉或替换限定词：`几乎是`→`是`、`也许`→`一定`、`似乎`→`明显`——把不确定改成确定。
2. 改语气助词：`算了吧`→`算了`、`好啊`→`好`、句末`呢/啊`被抹掉——态度从软变硬。
3. 把含蓄说白：内心戏的暗示被补成明说，"他看了她一眼"被扩写解释成"他其实是在心疼她"。
4. 补全留白：给开放式结尾加一句"从此以后"，给省略的对话加解释。
5. 改责任/因果方向：被动改主动、`因为`与`所以`互换、把"她让…"改成"…被她"——事实层就被改了。
6. 合并短句、抹掉作者靠断句制造的呼吸和节奏——语气层被改了。

**每处改动必须过三问，任一"是"就撤回：**

- 事实变了吗？（谁/何时/何地/因果/程度）
- 语气或态度变了吗？（确定↔猜测、强硬↔委婉、讽刺↔正经）
- 删掉这个改动，读者还能读懂吗？（读得懂就不该改）

**只允许改"形式错误"，不允许改"表达选择"。** 标点缺漏、错别字、衍字、`.` 用错的句号——这是形式错误；段落节奏、用词偏好、留白、口语腔调——这是表达选择。作者写得"不好读"不等于写错。

**两档共同的执行纪律：**

- 改动逐条可复原：记录 `章#段 / 原句 / 改句 / 理由`，理由里禁止出现"更顺""更好听""更高级"。
- 拿不准一律保留，写进争议清单交用户裁决；**不要替作者做决定**。
- 一轮只动一类（先标点、再错字、再断句），便于逐类复核。
- 改完做一遍"回读校验"：不看原文，只读改后段落，写下它的意思；再与原文意思对照。不一致就撤回。
- 机器校验器只能防"漏抄"和"整段重写"，**防不了"悄悄改意"**——所以必须有人过一遍语义，重型档尤其不能只信校验器。

**真实案例（都发生在既有项目里，可作为"该不该改"的标尺）：**

| 情形 | 处理 | 为什么 |
|---|---|---|
| 陈述式自问「她在想什么呢。」被补成「？」 | 撤回，保留句号 | 加问号把"自己念叨"变成"真的在问"，语气层被改 |
| 独立成段的「……啊」缺句末标点 | 只补「？」，不动「啊」 | 缺标点是形式错误；「啊」是语气，动它就是改意 |
| 「我们在家吃」疑似「你们」 | 不改，列争议清单 | 上下文里"我们=我和她"说得通，改主语等于改事实 |
| 「奶奶质问他」中"她→他"是错字 | 改 | 事实层原意就是"质问爸爸"，改后才是原意 |
| `啊。`/`吧。`/`好不好。` 句末用句号 | 不改 | 作者节奏，改成「？」或「！」都变语气 |
| 一段话 40 字没有逗号 | 只在语义停顿处加一个逗号 | 断句可以调，句子结构和用词不许动 |

## 总原则：修不是写

审校的目标是「让原文更好读」，不是「重写」。所有决定都服从一条：**不得改变原意**。

最小改动四原则：
1. 能改一个字就不改一个词，能改一个标点就不改字。
2. 改动必须可复原：任何一段改完，读者读起来仍是同一个意思、同一种语气。
3. 拿不准就保留原文，写进争议清单，不要自作主张。
4. 一次只做一类改动（先标点、再错字、再断句），避免混在一起说不清。

绝对禁止（14 条，来自真实事故）：
1. 改人名、地名、数字、英文、专有名词
2. 增删句子、合并或拆分段落
3. 改叙述视角与事实（年龄、时间、关系）
4. 把 `「」`（心声/强调）改成 `“”`（对白），或反过来
5. 把 `——` 改成逗号/句号
6. 把作者故意重复的 `？？？`、`哈哈哈哈`、`起起落落落落` 当错字改掉
7. 把口语、脏话、"不完整句"改成书面语
8. 换同义词求"文采"
9. 给没加引号的对话补引号（有些作者全书不用引号区分对白）
10. 改章节标题与编号
11. 把方言、港台用语、时代用语"标准化"
12. 加解释性旁白
13. 以"通顺"为名重排整句结构
14. 为凑改动率而改

允许修改的 12 类：缺句末标点、引号内缺句末标点、`。”，` 这类多余逗号、提示语缺冒号（「他说」→「他说：」，仅限说话类动词）、明显错别字、的/地/得、叠字衍字（"搭到到"→"搭到"）、问句用句号（明确发问时）、长句缺逗号（只在语义停顿处）、欧化语序（把"被"字句、长定语改顺，不换词）、指代不清（她/他→人名）、显性病句（成分残缺且不改意）。

## 轻型档

流程：
1. `normalize.py`（确定性排版，见阶段 2）
2. 逐章通读，按上面 12 类改，一次改一处
3. `final_check.py` 复检
4. **语义回读**：把改动过的段落并排列出，逐条确认"意思没变、语气没变"；变了的撤回（轻型档也要做，不能因为"改得少"就跳过）
5. 输出改动清单（章#段 原→改 理由），交付

**不做**：分卷、黄金范例、指代专项、争议清单（除非用户要）。

轻型档容易踩的坑：因为它"只改标点和小错"，人会放松警惕，于是顺手把 `算了吧` 改成 `算了`、把 `几乎` 删掉、把两个短句合成一句——这类改动量小但性质是改意，一律不许。

## 重型档

### 1) 定规范

先写一份 `proof/审校规范.md`，至少包含：
- 本书人物表（姓名/性别/关系）——指代判断要用
- 上面 14 条禁止 + 12 类允许（可裁到本书相关）
- 本书特例：这本书的引号用法、语气词、方言、故意重复
- 段末逗号的判断法：**看下一段**。若下一段是本句的延续（跨段断句），保留；若下一段是新句子，改成句号
- 交稿 JSON 格式

### 2) 黄金范例

主编亲手精修第 1–2 章（改动率通常 20–30%），把 `gold/ch001.original.txt` 与 `gold/ch001.corrected.txt` 一起给分卷编辑看。作用是定标准，防风格漂移。

### 3) 分卷

**按章数切，不按字数切**：每卷 8–12 章（经验值 10 章/卷），卷数 = ⌈总章数 ÷ 10⌉。

- 为什么按章数：真正撑爆 token 的是"章数 × 每章段数"，而每章段数差异可达 5 倍（150 段的大章 vs 30 段的小章）。按字数切会出现"一卷 35 章"这种灾难。
- 100 章 ≈ 10 卷；62 章 ≈ 6 卷；175 章 ≈ 18 卷（分两批跑，每批 ≤10 个子代理）。
- 极端长章（单章 >8000 字）可以单独立卷，或先按 `--split-chars` 在构建阶段分节、审校仍按整章处理。

```python
# 按章数切卷（每卷 10 章）
per = 10
parts = [chapters[i:i + per] for i in range(0, len(chapters), per)]
```

每卷一个独立子代理。**限 token 的 prompt 模板**：

```
你是资深中文编辑，只做最小改动审校。

【第一条硬约束，违反即作废】绝对不许改变作者原意：不许改事实（人/时/地/因果/程度），
不许改语气态度（限定词、句末助词、停顿都算），不许把含蓄处说明白、不许补留白。
只许改形式错误（缺标点、错别字、衍字、该用问号的地方用了句号）。
拿不准就原样保留，不要替作者决定。

【规范】<粘贴审校规范.md 的禁止清单与允许清单，控制在 300 字内>
【本书特例】<引号用法/语气/方言，3 行内>
【任务】审校第 3–15 章，共 511 段。原文见 src/ch003.txt …（每行一段）。
【输出】只输出 JSON 数组，不要解释过程：
[{"num":3,"title":"…","paragraphs":["…"]}]
  - 段数与顺序必须与原文完全一致；未改的段落原样抄回
  - 每段内不得有换行
【自检】改完跑：python scripts/check_part.py out/p1 3-15 --src _work/norm/chapters.json
```

关键：只给该卷源文 + 规范 + 输出格式，不要给全书；要求"只回 JSON"；**每卷 8–12 章（卷数=⌈总章数÷10⌉），一批不超过 12 章**。

### 4) 机器校验（每卷必跑）

```
python scripts/check_part.py _work/proof/out/p1 3-15 --src _work/norm/chapters.json --names 人名A 人名B …
```

阈值：
- 段数/段序/空段/段内换行 → 变则 ERROR
- 人名、数字、英文 token 计数 → 变则 ERROR
- 汉字数骤减 >15% → ERROR（漏抄）
- 相似度 <0.55 → ERROR（整段重写）；<0.8 → HEAVY（人工看）
- 单段长度比 <0.8 或 >1.3 → WARN（漏字/增写）
- 整章 0 改动或 >75% 段落改动 → WARN

### 5) 合并与全量质检

```
python scripts/merge_parts.py _work/proof/out -o _work/proof/merged.json --src _work/norm/chapters.json
python scripts/final_check.py _work/proof/merged.json --out _work/proof/质检.md
```

`final_check.py` 的残留项要逐类判读，不能一律改：
- 段末逗号：多为作者跨段断句（例：`…捏着毛毯一侧的边角，` 下一段 `把脸也一并罩了进去。`），保留
- 段末非句末标点：歌词、排比分号、`——` 续行、冒号引出行、`＊　＊　＊` 分隔，保留
- 重复标点 `？？？`/`！！`、省略号成串：作者语气，保留
- 单个省略号/单个破折号/半角标点/直引号/站点规避符：真错，改
- 叠字可疑：多数是误报（「现在在」「是是是」），逐条看

### 6) 语义复核（改意的最后一道闸）

机器校验只保证"没漏抄、没整段重写"，不保证"没改意"。合并后必须再做一遍人（或一次独立的子代理）的语义比对：

1. 只输出"改动过的段落"清单（`章#段 / 原 / 改`），逐条读出原句意思与改句意思，写成一句话。
2. 两句话不一致 → 撤回该改动，重新只做形式修复。
3. 重点盯上面列的六类隐性改意：限定词、句末助词、含蓄被说白、留白被补全、因果责任方向、短句被合并。
4. 复核结果写进交付说明：改了多少段、其中多少是纯标点、多少是字词、撤回了几处。

判断标准是"意思等价"，不是"改后更顺"。改后变顺但语气变硬、变确定、变直白，一样算改意。

### 7) 人称指代专项

单独扫一遍，别混在通读里。脚本思路：
- 段内只有女性名却出现单数「他」→ 可疑
- 段内只有男性名却出现「她」→ 可疑
- 「他」前面最近的人名是女性 → 可疑
- 前一子句出现第三者女性名、本子句以「她」开头 → 可疑
- 「她们」群体是否含男性 → 可疑

改法只有两种（白名单）：`她/他` → 人名；或补「人名 + 说」。校验时要求 before 与合并稿逐字一致，差异只允许这两种。

实例（用占位名说明三类典型改法，换成本书人名即可）：
- `甲冲乙摇摇头，她也没犹豫…` —— 第二个「她」实为在场的第三人「丙」→ 改「丙也没犹豫」
- `丙明明什么都没说，但她兀自解释起来` —— 前一句刚是「甲」开口 → 改「但甲兀自解释起来」
- `…说：“别恨自己。”` —— 说话人是「乙」（下一段可佐证）→ 补「乙说：」

### 8) 争议清单
